**A production-ready, high-fidelity Multimodal Visual Question Answering (VQA) dashboard that enables users to analyze images, upload local videos, or query public YouTube URLs with natural language questions.** Built with the Google Gemini 2.5 Flash API and LangChain, deployed via a modern Flask-powered glassmorphism interface with complete CI/CD automation.

## Key Features

1. **Dual-Tab Media Workspace**: Seamlessly switch between **Image VQA** and **Video VQA** tabs with sleek click-and-drag upload areas.
2. **Temporal Video Reasoning**: Upload local video files (MP4, WEBM, MOV, etc. up to 25MB) which are processed through the official Gemini Files API, audited for active status, and automatically deleted from both the cloud and local disk in `finally` blocks.
3. **No-Download YouTube VQA**: Paste a public YouTube link to instantly play the video inside the dashboard and query its visual and audio components directly using Gemini's native URI capabilities—requiring zero local download bandwidth.
4. **Recent Queries History Sidebar**: A beautiful log of your recent analyses cached locally via `localStorage`. Click on any historical card to instantly restore the video/image preview, your original question, response metrics, and markdown answers.
5. **Rich Markdown Answer Cards**: Support for parsing lists, bold text, inline code, blockquotes, and complex markdown structured tables generated by the Gemini model.
6. **Telemetry & System Metrics**: A clean hardware telemetry badge displaying the underlying LLM model, the resolved media modality, and request latency (in seconds).

## Architecture

**Three-layer modular architecture ensuring maximum separation of concerns:**

```
┌───────────────────────────────┐     ┌───────────────────────────────────┐     ┌──────────────────────────────────────┐
│        Transport Layer        │     │        Intelligence Layer         │     │             External API             │
│          (Flask API)          │────▶│           (VQA Engine)            │────▶│       (Gemini + LangChain SDK)       │
└───────────────────────────────┘     └───────────────────────────────────┘     └──────────────────────────────────────┘
   • HTML Templates & CSS/JS             • LangChain Message Construction          • ChatGoogleGenerativeAI (LangChain)
   • File size/type validation           • Gemini Files API upload orchestration   • google-genai SDK (Modern API Client)
   • Local temp-file lifecycles          • Temporal Prompt Engineering             • Multimodal inference & processing
   • Caching & JSON REST endpoints       • Token telemetry metrics                 • Native YouTube URI content generation
```

### Key Design Patterns

- **Separation of Concerns**: The transport layer (Flask Web App) is strictly isolated from the AI processing engine (`model.py`), making it straightforward to test components independently or swap out LLM endpoints.
- **Mock-Based Testing**: Unit tests in the `tests/` directory leverage `unittest.mock` to simulate Google Gemini API responses, allowing your CI/CD pipelines to run on every commit with zero API costs.
- **Safe Temporary Storage Lifecycle**: Local uploaded videos are securely cached in localized temp directories during the request lifecycle, ensuring they are deleted immediately from the host filesystem and the Gemini Files API upon resolution or request failure.
